## 📌 Overview

This archive aggregates essential theoretical and practical reference guides spanning core computer science, mathematics for machine learning, data engineering, and visualization libraries.

## 📁 Curriculum & Subject Breakdown

### 1. Python Programming Fundamentals
Complete 5-part lecture series covering core Python concepts:
- [`GitHub/Python/Python Fundamentals Part1.pdf`](GitHub/Python/Python%20Fundamentals%20Part1.pdf): Variables, primitive data types, basic I/O, operators, and expression evaluation.
- [`GitHub/Python/Python Fundamentals Part2.pdf`](GitHub/Python/Python%20Fundamentals%20Part2.pdf): Control flow, conditionals (`if`/`elif`/`else`), loops (`for`, `while`), and loop control (`break`, `continue`).
- [`GitHub/Python/Python Fundamentals Part3.pdf`](GitHub/Python/Python%20Fundamentals%20Part3.pdf): Python collections — Lists, Tuples, Sets, Dictionaries, and sequence operations.
- [`GitHub/Python/Python Fundamentals Part4.pdf`](GitHub/Python/Python%20Fundamentals%20Part4.pdf): Functions, scope, arguments (`*args`, `**kwargs`), lambda functions, and modular design.
- [`GitHub/Python/Python Fundamentals Part5.pdf`](GitHub/Python/Python%20Fundamentals%20Part5.pdf): Object-Oriented Programming (OOP) — Classes, objects, inheritance, polymorphism, and encapsulation.

### 2. Numerical Computing & Data Manipulation
- **NumPy Guide:** [`GitHub/Numpy/NumPy .pdf`](GitHub/Numpy/NumPy%20.pdf) — Multidimensional ndarray creation, vectorization, broadcasting, matrix algebra, and indexing.
- **Array Construction Lab:** [`GitHub/Creating_array_from_list.ipynb`](GitHub/Creating_array_from_list.ipynb) — Practical notebook demonstrating array transformations from native Python iterables.
- **Pandas Reference:** [`GitHub/Pandas/Pandas Notes.pdf`](GitHub/Pandas/Pandas%20Notes.pdf) — Series, DataFrames, indexing, filtering, handling null values, grouping, and aggregations.

### 3. Mathematics for AI & Machine Learning
- **Differential & Integral Calculus:** [`GitHub/Maths/calculus.ipynb`](GitHub/Maths/calculus.ipynb) — Derivatives, gradients, chain rule, partial derivatives, and optimization for gradient descent.
- **Probability Distributions:** [`GitHub/Maths/probab_dist (1).ipynb`](GitHub/Maths/probab_dist%20(1).ipynb) — Discrete and continuous distributions (Normal/Gaussian, Binomial, Poisson, Uniform), PDF, CDF, and statistical moments.

### 4. Data Visualization
- **Matplotlib Guide:** [`GitHub/Data_Visualization/Data Visualization - Matplotlib.pdf`](GitHub/Data_Visualization/Data%20Visualization%20-%20Matplotlib.pdf) — Plot customization, figure architectures, and chart types.
- **Seaborn Guide:** [`GitHub/Data_Visualization/Data Visualization - Seaborn.pdf`](GitHub/Data_Visualization/Data%20Visualization%20-%20Seaborn.pdf) — High-level statistical visualization, distribution plots, heatmaps, and pairplots.
- **Hands-on Assignment:** [`GitHub/Data_Visualization/Data Visualisation _Assignment.pdf`](GitHub/Data_Visualization/Data%20Visualisation%20_Assignment.pdf) — Structured visualization problem set.
