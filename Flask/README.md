
# Flask Web Applications & AI Assistant

A collection of Python and Flask projects demonstrating web application development, API integration, template inheritance, authentication, and AI assistant functionality.

## 📁 Repository Contents

| File / Folder | Description |
|---|---|
| `Ai_assistant/` | AI assistant project and related components |
| `Templates/` | HTML templates used by the web applications |
| `static/` | Static files such as CSS, JavaScript, and images |
| `API_with_Json.py` | Flask API demonstrating JSON data handling |
| `Login_website.py` | Login/authentication website implementation |
| `StepUp.ipynb` | Jupyter notebook for the StepUp project |
| `application.py` | Main Flask application |
| `template_inheritance.py` | Demonstrates Flask/Jinja template inheritance |
