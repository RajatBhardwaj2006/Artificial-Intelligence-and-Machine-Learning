# Machine Learning Analysis Notebooks

A collection of Jupyter notebooks demonstrating common machine learning and data analysis techniques, including anomaly detection, clustering, dimensionality reduction, and unsupervised learning.

## 📁 Notebooks

| Notebook | Description |
|---|---|
| `AnomalyDetection.ipynb` | Demonstrates anomaly and outlier detection techniques. |
| `DBSCAN.ipynb` | Demonstrates density-based clustering using DBSCAN. |
| `KMeans.ipynb` | Demonstrates K-Means clustering for grouping similar data points. |
| `PCA.ipynb` | Demonstrates Principal Component Analysis for dimensionality reduction. |
| `hierarchical_cluster.ipynb` | Demonstrates hierarchical clustering techniques. |

## 🧠 Topics Covered

- Anomaly Detection
- K-Means Clustering
- DBSCAN Clustering
- Hierarchical Clustering
- Principal Component Analysis (PCA)
- Data Visualization
- Unsupervised Machine Learning

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
