# Supervised Machine Learning

A collection of Jupyter notebooks and Python implementations covering fundamental and advanced supervised machine learning algorithms, along with practical prediction projects.

## 📁 Repository Contents

| File | Description |
|---|---|
| `AdaBoost.ipynb` | Adaptive Boosting algorithm |
| `Decision_Tree.ipynb` | Decision Tree classification |
| `Ensemble_Heterogenous.ipynb` | Stacking and Voting ensemble models |
| `Gradient_boosting.ipynb` | Gradient Boosting algorithm |
| `HousePricePrediction.csv` | Dataset for house price prediction |
| `House_Price_prediction.ipynb` | House price prediction project |
| `Iris.csv` | Iris flower dataset |
| `KNN.ipynb` | K-Nearest Neighbors algorithm |
| `KNN_Scratch.py` | KNN classifier implemented from scratch with visualization |
| `LROLS.ipynb` | LROLS machine learning implementation |
| `Linear_Regression.ipynb` | Linear Regression model |
| `Linear_Regression_1.ipynb` | Linear Regression implementation |
| `Linear_Regression_scratch.ipynb` | Linear Regression implemented from scratch |
| `LogisticRegressionScratch.py` | Logistic Regression implemented from scratch |
| `Naive_bayes.ipynb` | Naive Bayes algorithm |
| `Random_Forest.ipynb` | Random Forest algorithm |
| `Regularization.ipynb` | Lasso and Ridge Regression |
| `SVM_Classifier.ipynb` | Support Vector Machine classifier |
| `SVM_regression.ipynb` | Support Vector Regression (SVR) |
| `XGBoost.ipynb` | Extreme Gradient Boosting |
| `employee.ipynb` | Employee prediction/model performance project using L2 regularization |
| `employee_turnover.csv` | Employee turnover dataset |
