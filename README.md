## 🧬 About This Repository

Welcome to the **Artificial Intelligence & Machine Learning** master repository curated and maintained by **[Rajat Bhardwaj](https://github.com/RajatBhardwaj2006)**.

This repository is much more than a collection of tutorials. It represents an end-to-end, structured record of concepts investigated, mathematical derivations implemented from scratch, datasets analyzed, deep neural networks trained, autonomous agents deployed, and practical systems built.

### 💡 Core Engineering Principles
- **Understand the Math:** Ground every model in calculus, linear algebra, probability, and optimization surfaces before invoking high-level `.fit()` APIs.
- **Implement from Scratch:** Code algorithms like Linear Regression, Logistic Regression, KNN, and Gradient Descent in pure NumPy to master their inner mechanics.
- **Work with Real-World Data:** Clean, preprocess, and evaluate noisy distributions (e.g. global air quality, residential sales, financial defaults).
- **Scale to Modern AI:** Advance from classical statistics to deep tabular/vision models, PyTorch Deep Q-Networks (DQN), and autonomous LLM agents.
- **Ship to Production:** Package models behind Flask REST microservices, interactive Streamlit dashboards, and persistent databases.

## 🏆 Featured Capstone Projects

<div align="center">

### 1. 💳 CreditWise Loan Approval System
*Predicting Loan Default Risk via Supervised Machine Learning*

```text
Applicant Records ──> Imputation & Scaling ──> Balanced Classifier ──> Confusion Matrix & ROC-AUC (0.90+)
```
- **Folder:** [`Projects/CreditWise_Loan_System/`](Projects/CreditWise_Loan_System/README.md)
- **Problem Statement:** Automate credit eligibility checks and minimize non-performing asset risk for lending institutions.
- **Key Techniques:** Missing value imputation, standard feature scaling, handling imbalanced class distributions, and multi-metric evaluation (Precision, Recall, F1-score, ROC-AUC).

---

### 2. 🎮 Flappy Bird Deep Q-Network (DQN) Agent
*Autonomous Arcade Navigation via PyTorch Reinforcement Learning with CUDA Support*

```text
Game State (Gymnasium) ──> Deep Q-Network ──> Epsilon-Greedy Action ──> Experience Replay Buffer ──> Target Net Sync
```
- **Folder:** [`Reinforcement_Learning/Flappy_bird/`](Reinforcement_Learning/Flappy_bird/README.md)
- **Key Techniques:** Deep value approximation via neural networks, experience replay memory buffer to eliminate sample autocorrelation, target network synchronization, and automated NVIDIA CUDA acceleration.

---

### 3. 🤖 Autonomous Multi-Agent Intelligence System
*Real-Time Video Transcription, Market Research & Stateful SQLite Memory*

```text
User Query / Video URL ──> Agent Router ──> YouTube Transcripts / YFinance API ──> Groq LLM Inference ──> Streamlit UI
```
- **Folder:** [`AIAgent/`](AIAgent/README.md) & [`Projects/Youtube_video_analyzer/`](Projects/Youtube_video_analyzer/README.md)
- **Key Techniques:** ReAct tool calling, automated timestamp generation, SQLite persistent agentic memory across user sessions, and a Streamlit frontend dashboard.

---

### 4. 🛒 SmartCart Customer Segmentation System
*Unsupervised Behavioral Clustering for Retail Analytics*

```text
Customer Demographics & Spending ──> Feature Normalization ──> WCSS Elbow Curve ──> K-Means Clustering ──> PCA 2D/3D Projection
```
- **Folder:** [`Projects/SmartCart_Cluster_system/`](Projects/SmartCart_Cluster_system/README.md)
- **Key Techniques:** Within-Cluster Sum-of-Squares (WCSS) optimization, Silhouette score validation, and PCA dimensionality reduction to visualize consumer personas.

---

### 5. 🏡 Real Estate Valuation Predictor
*End-to-End Multivariate Regression Modeling*

```text
Property Features ──> Outlier Pruning ──> One-Hot Encoding ──> Regularized Regression ──> RMSE / R² Evaluation
```
- **Folder:** [`Projects/Minor_Projects/House_price/`](Projects/Minor_Projects/House_price/) & [`Supervised_Learning/`](Supervised_Learning/README.md)
- **Key Techniques:** Multicollinearity diagnosis, $L_1$/$L_2$ regularized loss minimization, and cross-validated error metrics.

## 🛠️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/RajatBhardwaj2006/Artificial-Intelligence-and-Machine-Learning.git
cd Artificial-Intelligence-and-Machine-Learning
```

### 2. Setup Virtual Environment
```bash
# Windows:
python -m venv venv
venv\Scripts\activate

# Linux / macOS:
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Unified Dependencies
```bash
pip install numpy pandas scipy scikit-learn xgboost matplotlib seaborn jupyter torch gymnasium flappy-bird-gymnasium agno groq openai requests beautifulsoup4 flask streamlit python-dotenv pyyaml
```

### 4. Configure Environment Credentials
For generative AI modules (`AIAgent/`, `Flask/Ai_assistant/`, `OpenAI/`), add your API keys to a `.env` file:
```env
GROQ_API_KEY="your-groq-api-key-here"
OPENAI_API_KEY="your-openai-api-key-here"
```

Open and explore any interactive notebook across the repository:
```bash

```

```bash

python Flask/Ai_assistant/main.py
```
