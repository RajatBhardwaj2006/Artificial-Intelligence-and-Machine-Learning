# Data Visualization with Python

A collection of Python scripts and Jupyter Notebooks demonstrating different data visualization techniques using Python. This repository contains examples of commonly used plots and visualization methods useful for data analysis, exploratory data analysis (EDA), and machine learning.

## 📁 Repository Structure

```text
.

├── Box_plot.ipynb

├── Pie_chart.ipynb

├── Stack_plot.ipynb
├── line_plot.ipynb
├── modern_PLT.ipynb
├── plot_train_valid.ipynb
├── ano.py
└── practice.py
```

## 📊 Visualizations Covered

### Bar Chart
`Bar_chart.ipynb`

Demonstrates how to create bar charts for comparing values across different categories.

### Box Plot
`Box_plot.ipynb`

Demonstrates box plots for understanding data distribution, including:

- Median
- Quartiles
- Interquartile Range (IQR)
- Outliers
- Data spread

### Histogram
`Histogram.ipynb`

Demonstrates histograms for visualizing the frequency distribution of numerical data.

### Pie Chart
`Pie_chart.ipynb`

Demonstrates pie charts for representing proportions and percentages of categorical data.

### Scatter Plot
`Scatter_plots.ipynb`

Demonstrates scatter plots for analyzing relationships and correlations between two numerical variables.

### Stack Plot
`Stack_plot.ipynb`

Demonstrates stack plots for visualizing how multiple quantities change over time or across categories.

### Line Plot
`line_plot.ipynb`

Demonstrates line charts for displaying trends and changes in data.

### Modern Matplotlib
`modern_PLT.ipynb`

Contains examples of modern Matplotlib visualization techniques and styling approaches for creating cleaner and more informative plots.

### Training & Validation Plot
`plot_train_valid.ipynb`

Demonstrates visualization of training and validation performance, useful for analyzing machine learning model behavior and identifying issues such as overfitting.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project

```bash
cd <repository-name>
```

### 3. Install Required Libraries

```bash
pip install numpy pandas matplotlib jupyter
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Open any `.ipynb` file to explore the visualization examples.
