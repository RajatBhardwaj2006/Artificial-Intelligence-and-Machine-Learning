## 📂 Repository Structure

The repository is organized into the following core project directories[cite: 1]:

* **`CreditWise_Loan_System`**: A financial system focused on credit evaluation and loan processing, developed as a minor project[cite: 1].
* **`Minor_Projects`**: Contains foundational machine learning implementations, specifically focusing on house price prediction and Iris flower classification[cite: 1].
* **`SmartCart_Cluster_system`**: Implements a smart cart clustering solution designed for retail data grouping and customer analysis[cite: 1].

---

## 🚀 Project Overviews

### 1. CreditWise Loan System
* **Objective**: Evaluate loan eligibility and manage credit risk using data-driven approaches.
* **Key Focus**: Financial data analysis, classification algorithms, and automated decision-making workflows.

### 2. Minor Projects (House Price & Iris Flower Prediction)
* **House Price Prediction**: Uses regression algorithms to predict housing prices based on various structural and geographical features.
* **Iris Flower Prediction**: Implements multi-class classification to accurately categorize Iris flower species using sepal and petal dimensions.

### 3. Smart Cart Cluster System
* **Objective**: Apply unsupervised learning and clustering techniques to retail or shopping cart data[cite: 1].
* **Key Focus**: Customer segmentation, grouping behavior, and pattern recognition.
